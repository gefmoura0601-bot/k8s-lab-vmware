# Identidade visual

O dashboard utiliza o ícone colorido oficial do Kubernetes, sem modificação da geometria ou das cores, obtido do repositório [`cncf/artwork`](https://github.com/cncf/artwork/tree/master/projects/kubernetes).

- arquivo local: `web/public/kubernetes-logo.svg`;
- cor primária: `#326CE5`;
- formato: SVG;
- uso: identificação visual de uma ferramenta relacionada ao Kubernetes.

Kubernetes é uma marca registrada da Linux Foundation. O uso do logo está sujeito às [Kubernetes Branding Guidelines](https://github.com/kubernetes/kubernetes/blob/master/logo/usage_guidelines.md) e às regras de trademark da Linux Foundation.

Esta ferramenta é um assessment independente. O uso da marca não representa certificação, patrocínio ou endosso pelo Kubernetes, CNCF ou Linux Foundation.
